# Phase 52 - UI Clutter Removal

The FreeCAD Match world removes telemetry boxes from the model area by default. The geometry truth side panel and bottom metric boxes are hidden in the fullscreen world route and FreeCAD-match mode.

Label behavior:

- Clean: hides target/FOV labels and keeps the model unobstructed.
- Tactical: shows core camera/launcher/target explanation.
- Debug: shows expanded conversion/geometry information.
