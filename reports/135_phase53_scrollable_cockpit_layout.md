# Phase 53 - Scrollable Cockpit Layout

The one-screen 1080p constraint was removed. The cockpit may now exceed one viewport height so the 3D model does not need to shrink.

- Cockpit shell uses vertical scrolling.
- Main dashboard sections are stacked in operational priority order.
- 3D hero comes first.
- Camera HUD is secondary and may be collapsed or opened fullscreen.
- Mission cards appear after scrolling.

This is intentional for KTR review: the primary visual proof is the large 3D model, not a compressed all-in-one dashboard.
