# Phase 52 - CAD Edges and Materials

CAD edge outlines are enabled by default in FreeCAD Match mode using Three.js `EdgesGeometry`. The edge color is dark gray on the light FreeCAD-style background and cyan/subtle in tactical dark modes.

Material normalization keeps the reconstructed STEP palette readable:

- muted CAD red / dark red
- light gray / white panels
- visible graphite for dark mechanical parts
- metallic gray hardware
- cyan sensor/camera highlights
- yellow launcher/axis accents

The CAD Debug mode includes a material table with color, roughness, metalness, and mesh count.
