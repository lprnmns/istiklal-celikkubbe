# Phase 52 - Camera Framing and Controls

The viewer now computes the GLB bounding box and uses deterministic model fitting. FreeCAD Match uses an OrthographicCamera and fits the full KTR silhouette with margin. Showcase and Tactical modes use a perspective camera.

Presets:

- FreeCAD Match
- Operator
- Front
- Side
- Top
- Rear
- Launcher Axis
- Target POV
- Reset
- Fullscreen

Keyboard shortcuts: `R`, `F`, `L`, `O`, and numeric presets `1` through `7`.
